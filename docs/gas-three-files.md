# GAS版：3ファイル構成

`gas/index.html`、`gas/Code.gs`、`gas/bridge.html` を使用します。利用者・管理者・最高管理者・メモ帳を同じindexから表示します。読みやすさ優先の新デザインです。

## 設置

1. 既存のApps Scriptプロジェクトで `Code.gs` を置き換えます。同じ関数を別の `.gs` に重複して追加しないでください。
2. HTMLファイル `index` と `bridge` を作成、または置き換えます。名前は小文字です。追加のCSS・JavaScript・画像ファイルは不要です。
3. 既存のスクリプトプロパティ（スプレッドシートID、各パスワード、Supabase設定）は保持してください。
4. 「デプロイ → デプロイを管理 → 編集」で新しいバージョンに更新します。

## 開く画面

- デプロイURL：利用者画面
- デプロイURLの末尾に `?page=admin`：管理者画面
- 最高管理者：管理者ログインで既存の `K:` 付きパスワードを使用
- メモ帳：管理者画面の「メモ帳」から開く（別HTMLファイルは不要）

画面・サムネイル・ローカルのCSS/JavaScriptをindexへ同梱しています。GAS画面は `google.script.run` で直接通信します。bridgeは既存のRender/GitHub画面との互換用です。チャット・お知らせ・アンケートの保存先は既存のSupabaseを継続し、RealtimeのライブラリはHTTPS CDNから読み込みます。ゲーム本体は従来の外部ページを開きます。

## 検証

`node tests/gas-three-files.cjs` でテンプレート分岐、全画面のJavaScript構文、GAS呼び出し、配信プロキシの認証を検証できます。画面確認はテスト用のGAS応答を使用しています。実際のGASへのデプロイと実データ通信は未検証です。
