# アイテムとキー配置

Java 26.1のデータに掲載された1505種類（airを除く）を検索できます。効果未実装のアイテムは画面に表示します。全効果の再現は完了していません。

418種類の立方体ブロックは独自の簡易色・テクスチャで設置可能。階段など特殊形状、レッドストーン装置、戦闘、醸造などは効果未実装です。食品は基本の満腹回復のみ、道具は適した素材の採掘速度が変化します。毒やエンチャントなど付随効果は未実装です。

E：インベントリ、F：オフハンド持ち替え、Q：落とす、1〜9・ホイール：ホットバー、Shift：しゃがむ、ControlまたはW2回：ダッシュ、Space：ジャンプ。マウス左長押し：破壊、右：設置・食事。オフハンドのブロックはメインハンドが空のときに設置できます。
