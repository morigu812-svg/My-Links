# LINK BASE TOWN / LINK BASE Virtual

未来の日常の町。テーマは未来の世界で、暮らしは今と変わらない日常そのもの。ソロ生活と最大16人の街マルチプレイ。人間アバター、14人の歩くNPC住民、3人の家族NPC、入って歩ける自分の家とスーパー、iPhone風スマホを追加。

## 町
計画的な日常生活の町。北に住宅街（三角屋根の一戸建て）と自分の家、東に商店街（パン屋・カフェ・コンビニ・花屋）とスーパー、南に駅・学校・レース会場、西に公園・図書館・病院、中央に広場と植物園。建物は低層中心で、窓は暖かい色。ネオンはレース会場のゲート周辺だけに残しています。看板は日本語でわかりやすく（スーパー、パン屋、カフェ、駅、公園、学校、病院、図書館）。
水辺のプロムナードと遠景のスカイラインは残しています。NPCと家族は実際の利用者ではありません。

## スマホ
iPhone風の画面。ステータスバー（日本時間の時計、電波・5G・バッテリー）、Dynamic Island、壁紙、大きな時計ウィジェット、アプリアイコンのグリッド（自分の家・スーパー・レース会場・中央広場・家族・持ち物・設定・街の案内）、下部のドック（家・スーパー・持ち物・閉じる）。各ページは画面の中に表示され、ナビゲーションバーからホームへ戻れます。
スマホボタン（PCはM）から自分の家、スーパー、レース会場、中央広場へ移動。家では家族との会話・名前変更・部屋のソファ色の変更。スーパーでは食材を15CRで購入し、家族との食事で1日1回80CR。家・スーパー・家族の初回街めぐりは120CR。
アバター、家族、部屋の色、食材、位置、CR、レース記録は同じブラウザのlocalStorageに保存。端末間同期なし。

## アバター
ロボット要素なしの、人間に寄せたアバター。頭は小さめのリアル寄りの頭身で、目・眉・鼻・口があり、髪型はショート／ロング／ポニーテールの3種類。服は発光しない日常のジャケットとシャツ。テンプレートはシティボーイ／ストリート／シティガール／カジュアルの4人。色（服・シャツ・肌）と身長も変えられます。歩行アニメーション付き。古いセーブのロボット／バイザー／ヘルメット設定は読み込み時にショートヘアへ変換されます。

## 操作
スマホ：左半分長押しで前進、離すと停止、右半分スワイプで旋回。街の通常速度34、Shift50、Control/Command72単位/秒。PCはWASDとマウス、Eで近くの施設、Mでスマホ。ゲーム中の選択・長押しメニュー・ズーム操作を抑制（ブラウザ固有の操作は端末に依存）。

## レース
3周から1周へ短縮。約6975単位、通常ペースで約34秒。街・森林・海上・光トンネルの4区間。4つの収集イベント各25CR、ジャンプゲートでエネルギー回復。CPU5台は直近8完走の平均70%と最速30%を使い、次レースの基準速度135〜345を決定。初回195、旧コースのベストラップがある場合は縮尺換算して推定。極端な瞬間ワープなし。オンライン対戦レースは未実装。
旧コースの記録は保持しますが、コース形状と周回数が変わったため旧レース途中の再開は行いません。新コースの途中保存・再開には対応。

## 報酬と接続
街の光は日本時間で毎日復活、ソロ10CR、他プレイヤーと接続中40CR。協力移動60秒かつ30距離で200CR。レース完走1位100CR、上位3位60CR、その他30CR。CRはブラウザ保存の架空通貨です。
同じルーム名で接続中のみニックネーム・アバター・位置をSupabase経由で共有。通信失敗時はソロで継続。チャット認証情報は使用しません。
Three.js 0.170.0 MIT。音あり／音なしを開始前に選択。スマホ上限30fps、PC60fps。
