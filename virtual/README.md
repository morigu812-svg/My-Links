# LINK BASE VIRTUAL

`/virtual/`の3D未来都市。管理者画面の「バーチャルゲーム」から開きます。

## できること
- 音あり／音なしを選んで入場。4つのアバターテンプレート。
- 名前・服色・発光色・肌／本体色・頭部スタイル・身長のカスタマイズ。
- 左半分を長押しで前進、離すと停止。右半分の左右スワイプで旋回。
- PCはWASDで前後左右に移動。街をクリックするとマウスで方向転換（Escで解除）。マウスロック非対応時はドラッグで方向転換。矢印キー操作にも対応。Eで近くのレース入口を開きます。
- スカイライン・レースゲートから3周レース／フリー走行へ。
- 街の12個の光を集めて探索。レースから街へ戻れます。
- アーケードはCOMING SOONの案内のみで、追加ミニゲームは未実装。

## 保存・公開範囲
- 1人用。街のロボットはNPCで、ほかの利用者ではありません。
- アバター・街の位置と向き・取得した光・レースのベスト記録と進行を、このブラウザのlocalStorageに自動保存します。約5秒ごと／光の取得／退出時などに保存します。
- セーブは同じサイト・同じブラウザでのみ使用できます。サイトデータの削除やプライベートブラウズ終了で失われる場合があります。他端末への同期はありません。
- 起動時は毎回サウンドを選択します。保存データだけで自動再生はしません。
- 音声は端末のWeb Audio APIで生成。外部通信や音声ファイルなし。
- Three.js 0.170.0をvendorに同梱。MITライセンスを同梱。
- 静的ゲームなのでURLは管理者認証で保護していません。管理者画面に起動メニューを設置しています。
- 既存のGAS/Supabaseの認証・チャット・リンクデータへは接続しません。

## 描画負荷
- アンチエイリアス無効、描画倍率はスマホ1倍・PC最大1.25倍。
- スマホは30fps、PCは60fpsを上限とし、タイトル・設定画面は24fpsに制限。
- 遠景の建物・空中交通・星の数を減らし、街とレースの操作・機能は維持。
