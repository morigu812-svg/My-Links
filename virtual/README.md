# LINK BASE VIRTUAL

`/virtual/`の3D未来都市。管理者画面の「バーチャルゲーム」から開きます。

## できること
- 音あり／音なしを選んで入場。4つのアバターテンプレート。
- 名前・服色・発光色・肌／本体色・頭部スタイル・身長のカスタマイズ。
- 左半分を長押しで前進、離すと停止。右半分の左右スワイプで旋回。
- PCはW/↑で前進、A/D/左右キーで旋回。Eで近くのレース入口を開きます。
- スカイライン・レースゲートから3周レース／フリー走行へ。
- 街の12個の光を集めて探索。レースから街へ戻れます。
- アーケードはCOMING SOONの案内のみで、追加ミニゲームは未実装。

## 保存・公開範囲
- 1人用。街のロボットはNPCで、ほかの利用者ではありません。
- アバター設定はこのタブのsessionStorageに保存。アカウントへの永続保存・他端末同期は行いません。
- 音声は端末のWeb Audio APIで生成。外部通信や音声ファイルなし。
- Three.js 0.170.0をvendorに同梱。MITライセンスを同梱。
- 静的ゲームなのでURLは管理者認証で保護していません。管理者画面に起動メニューを設置しています。
- 既存のGAS/Supabaseの認証・チャット・リンクデータへは接続しません。
