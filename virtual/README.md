# LINK BASE Virtual

3Dの街とCPU対戦レース。街のマルチプレイは同じルームコードを入力すると最大16人で参加できます。通信失敗時もソロで続行できます。

スマホ：左半分の長押しで前進、離すと停止。右半分のスワイプで方向転換。レースにはカーブアシストがあります。
PCの街：WASDとマウス、Shiftでダッシュ、Control/Command中は超ダッシュ。レース：A/D、Spaceでブースト、Control/Commandでターボ。

街の光は日本時間で毎日復活し、ソロ10CR、他プレイヤーと接続中は40CR。マルチプレイで60秒移動し30距離以上進むと200CR。CPUレースの完走は1位100CR、2〜3位60CR、その他30CR。CRはゲーム内の架空通貨です。

アバター、街の位置、取得した光、レース進行と記録、CRは同じブラウザのlocalStorageに保存。削除すると失われ、端末間同期はありません。CRはローカル保存のため競技用に改ざんを防ぐ設計ではありません。

マルチプレイ中のみニックネーム、アバター、位置をSupabase経由で共有します。ブラウザごとの秘密トークンで自分の接続を更新します。チャットや既存の利用者認証データは利用しません。レースはCPU対戦で、オンライン対戦レースは未実装です。

開始前に音あり／音なしを選択。Three.js 0.170.0を同梱（MIT）。スマホ30fps、PC60fpsを上限に描画します。
