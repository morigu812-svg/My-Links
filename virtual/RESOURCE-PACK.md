# 日本語表示と利用者の素材読み込み

アイテム名はJava 26.1の日本語名に対応しています。インベントリとホットバーに見本画像を表示します。素材未読み込み時は自作の簡易画像です。

開始画面の「本物のテクスチャを読み込む」から、利用者自身が用意したJava版リソースパックZIP、またはゲーム本体JARを選択できます。assets/minecraft/textures/block、textures/item、models/blockを読みます。画像とモデル定義はそのブラウザのIndexedDBへ保存し、外部サーバーへ送信しません。120MB以下、展開対象64MB以下、各ファイル4MB以下です。ストア型ZIP・Deflateに対応。ZIP64や暗号化ZIPは未対応です。

対応済みの立方体ブロックはモデル定義から各面のテクスチャを読み、画像とゲーム内で同じ素材を使用します。アニメーション、特殊形状の完全再現は未対応です。画像・ゲーム本体ファイルそのものはリポジトリに同梱していません。

左側の仮想スティックは前後左右・斜めのアナログ移動。右側は視点ドラッグとタッチマウス。視点感度は初期2倍、開始画面と一時停止メニューから0.5〜4倍で変更できます。

このゲームは独自実装です。アイテムの全効果（戦闘・液体・醸造・レッドストーン・乗り物等）は未完成であり、カタログへの掲載は機能実装を意味しません。

素材の利用条件は利用者が用意するパックに従ってください。Minecraft関連の公式案内：https://www.minecraft.net/en-us/usage-guidelines

HP・満腹度は各20ポイントを10個のピクセルアイコンで表示。落下3ブロック超でダメージ、移動で空腹、満腹時の自然回復、食事による満腹回復があります。HPが0になると広場で再スタートします。タッチマウスは右最下部、スティックは左下、ホットバーと各操作はその上へ配置しています。
