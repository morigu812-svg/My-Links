# 採掘と自動化

3Dの採掘場でピッケルを振り、鉱石を運搬します。手作業の精製は1個1.5秒。精製品をトラックへ積み、卸売配送で売上を得ます。

ピッケル強化、並列精製機、自動積載機、専用採掘機、トラック増強を順に購入できます。専用採掘機は精製・積載設備と16個の納品で解放されます。自動積載後は満載、または積載開始から4秒で出荷します。

WASD・地面クリックで移動、Space長押しで作業。タッチは左スティックと右の作業ボタン。音は開始前に選択。ブラウザ内のquarry名前空間に保存し、閉じている間は生産しません。以前のfactoryセーブとゲームはflow-foundry.htmlに保持しています。

検証: node virtual/factory/quarry-state.test.mjs
