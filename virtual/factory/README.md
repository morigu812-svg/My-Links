# 作業ゲー / FLOW FOUNDRY

採掘タップ→一括回収→採掘タワー・精製プラント・ドローン港を建設する高速成長ゲームです。PC・タッチ対応。画面ドラッグで都市を回転。開始時に音あり／音なしを選択します。

連打で12コンボまで成長し、一定時間生産2倍。手動回収にはコンボボーナス、自動回収には精製倍率が適用されます。20秒ごとに8秒間の特急便イベントが発生します。都市ランクに応じて1回ずつ共通CRを獲得します。ランク12から新しい街区へ移動でき、設備・資材をリセットする代わりに永続生産ボーナス+20%ずつが付きます。

街・設備・資材はfactoryキーでブラウザに自動保存（約3秒・回収・建設・退出）。留守中は最大120秒分の素材がたまります。一時停止中は生産停止。ソロ用で、他端末同期・マルチプレイはありません。

3D建物は独自の手続き生成モデル。スマホ30fps、PC60fpsを上限に描画。ゲーム一覧のサムネイルは実際に描画したゲーム画面です。資材・CRは架空のゲーム内数値であり、金銭的な価値・課金・換金はありません。
