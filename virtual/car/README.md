# CITY DRIVE ACADEMY

LINK BASE GAMES用の普通AT教習・自由走行ゲーム。`virtual/car/`を静的配信します。Three.jsは既存の`virtual/vendor/three.module.min.js`を使い、走行自体にビルドは不要です。別ブラウザへの引き継ぎには既存Supabaseの保存APIを使用します。

## この版で遊べる内容

- 11メーカー・50車種の選択。軽、ハッチバック、セダン、ワゴン、SUV、ミニバン、スポーツ、EVなどで車重、駆動力、寸法、グリップを変更。メーカー名・車名は車種識別用です。車体は手続き生成した共通形状を基にした近似表現、性能値もゲーム用の設定で、実車の公認データや精密3Dモデルではありません。
- WASD/矢印、左側のフローティング・アナログスティック、独立したマルチタッチペダル。P/R/N/D/M、Dの自動変速、Mの6段選択、サイドブレーキ、ベルト、左右確認、左右ウィンカー、ハザード、前照灯。
- 車重、トルク曲線、ギア比、出力、転がり抵抗、空気抵抗、勾配、路面摩擦と制動を使う簡易縦運動。横運動は摩擦上限付きの自転車モデルです。ABS・荷重移動・タイヤ温度・サスペンション・破損・実車別駆動系を精密計算する車両工学シミュレーターではありません。
- 梅田周辺の雰囲気を意識した約2km四方の架空グリッド都市。実際の梅田の道路や建物を再現した地図ではありません。ビル、街路樹、公園、噴水、歩道、センターライン、停止線、横断歩道、信号、速度標識、一時停止標識、バス停、駐車枠、側溝、踏切と列車を収録。道路設備を網羅した都市デジタルツインではありません。
- 交通量0/12/30/60台、ドライ/ウェット、画質3段階。AI車両は左側車線の矩形経路を走り、信号、一時停止、踏切、前方車を見て減速。交通量を選んでも発進場所直近のAIは安全のため除外するので、実際の台数はHUDに表示します。歩行者は収録した横断歩道の信号に合わせて移動。全交通主体の実行動は網羅しません。

## 教習と解放条件

12課題を順番に修了します。乗車と発進停止、速度調節、合図付き右左折、S字、クランク、坂道発進、後退車庫入れ、場内検定、路上走行、踏切と危険予測、交差点と車間距離、卒業技能検定です。安全、操作、走行位置、速度、確認・合図の5区分各20点、合計100点から減点。各課題85点以上で、重大なミスがないことが条件です。技能12課題と20問の学科90点以上の両方でゲーム内免許を発行し、フリー走行を解放します。

85点という技能合格線、課題の時間、チェック地点、操作による安全確認はゲーム独自の基準です。実際の教習時限数・合宿日数・応急救護実習・免許試験の全課程を代替せず、現実の免許や資格は取得できません。

## 違反、事故、取締り

公道で信号、一時停止、速度、通行区分、歩行者、車間、ベルト、合図、踏切を判定します。判定は停止線の前側バンパー位置、継続時間、停止記録などを使います。黄色信号の停止可能性は簡易制動距離によるモデルです。同時検出は基礎点数の最も高い1件を演出対象とします。すべての現実の違反成立条件、併合関係、免許行政の例外を判定するものではありません。

違反時はパトカーが後方から接近し、警察官が降りて車両へ歩き、切符の確認画面が出ます。違反点数は演出開始時点で記録するため、演出中に更新しても点数が消える設計ではありません。教習中は模擬取締りとして技能評価に反映し、公道フリー走行では累積点数を加算します。

事故は「運転者の不注意による、けがのない物損」「同責任の建造物損壊」「同責任の軽傷15日未満」の固定シナリオです。実際の衝突速度から負傷程度や過失割合を断定しません。安全運転義務違反の基礎2点に、収録した条件の事故付加点数を合わせます。その他の事故・被害程度・救護義務違反等を網羅してはいません。救護・危険防止・報告の確認まで操作を止めます。未処理事故は記録に残り、更新後も処理を要求します。

日本の制度に合わせた累積加点方式と、前歴に応じた停止・取消の基本閾値を使用します。ただし違反者講習、点数計算の特例、欠格期間の全区分、刑事手続・罰金・保険等は扱いません。停止はゲーム内日数で示し、補習学科に合格するとゲーム内日程を停止期間満了まで進めます。取消後の再取得はゲーム独自の1年経過と再教習に整理しています。現実の行政処分を確定する機能ではありません。

## 保存と更新

教習・学科・免許・違反・未処理事故・車種設定はIndexedDBに保存します。既存LINK BASEの認証データには触れません。保存が制限されたブラウザではその旨を表示し、そのページ内でのみ継続します。サーバー同期・端末間共有・不正改変防止はありません。

スクリプト/スタイルにはacademy1の更新キーを付け、サービスワーカーを更新します。以前の自由走行版の一時的な走行距離は引き継ぎません。最初は免許未取得です。

## 2026-11-26 操作・保存・フリー走行更新

- メニューの「セーブの引き継ぎ」で英字と数字を含む12〜64文字の専用コードを設定。登録した後は教習・学科・免許状態・車両/交通/路面設定の変更を自動クラウド保存する。別ブラウザでは同じコードで復元。走行途中の位置や損傷は引き継がない。
- 引き継ぎ先は既存のMyLinks Supabase。`supabase/driving-transfer.sql`を適用済み。テーブルは非公開・RLS有効・直接アクセス権なし。RPCはコードのハッシュを資格情報として照合するため、ログインなしで実行できる設定は意図的。コード原文はサーバーやIndexedDBに保存しない。コードを知る人には読み書きできる。一般パスワードの流用は避ける。
- ブラウザにはIndexedDBで連携用ダイジェストと版番号を保持。サーバーの版番号が変わっていれば古いブラウザからの上書きを停止。再読込で勝手にアップロードしない。別ブラウザを使い始める際は必ずコードで最新記録を読み込む。コードの重複登録では既存データを上書きしない。通信失敗は画面に表示し、端末内の記録は保持する。
- タッチのギアはネイティブselectから独立したP/R/N/D/Mボタンへ変更。停車中のタップで自動ブレーキ保持、アクセル入力で解除。走行中の前後切替は拒否。ペダルとスティックはポインターごとに管理し、キャンセル・フォーカス喪失で解除する。
- 場内の上限：発進停止20、速度課題35（目標25〜35）、左右折30、S字15、クランク12、坂道20、後退12、場内検定30 km/h。速度判定・HUDは同じ課題データを参照。
- フリー開始時に真面目/暴走を選択。免許取得条件は共通。真面目は既存の違反・事故処理を継続。暴走は免許記録を更新せず、運動エネルギーと車重から簡易損傷を計算、出力低下・車体変形・破片・樹木破壊・他車の走行停止を表現。損傷85%以上で走行不能、修理で開始地点へ戻る。建物の構造崩壊や実車の衝突解析を再現するものではない。演出は最大48破片を再利用。
- 検証：既存28件＋追加8件（保存競合、コード、損傷、教習速度、実ゲームのタッチ入力経路）。DBはanon権限で作成/取得/更新/重複/誤コード/競合をトランザクション内検証しロールバック。
