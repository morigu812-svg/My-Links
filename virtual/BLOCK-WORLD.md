# Block World

/virtual/ はブロック建築モードです。64×64の街、8素材、破壊・設置・ジャンプ・ダッシュ。一人称で、家・学校・店の内側も編集できます。底の基盤は変更できません。1ワールド2500か所までの編集と位置をブラウザ保存します。保存キーはvoxelで、以前の街のセーブとは別です。

PC：WASD、マウス、Spaceでジャンプ、Shiftでダッシュ、Control/Commandで加速。左クリック/Eで破壊、右クリック/Fで設置。1〜8で素材選択。最初のクリックでマウス操作を開始します。タッチ：左長押し前進、右ドラッグ視点、ボタンで破壊・設置・ジャンプ。

探索の光は日替わりで20CR。建築操作を繰り返すだけでは通貨は増えません。CPUレースはそのままアクセスできます。

以前の街・家族・施設遊び・マルチプレイはlegacy.htmlに残しています。新しいブロックワールドの建築は現在ソロ・ブラウザ保存のみで、マルチプレイ同期は未実装です。Three.jsは既存のMITライセンス同梱版を使用します。
