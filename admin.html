管理者機能の使い方

知りたい機能を選ぶと、操作手順が開きます。

リンクの追加・編集

「リンクを追加」を押し、タイトルとURLを入力します。フォルダーを階層にする場合は「勉強/数学」のように指定します。登録済みのリンクはカードの「編集」から変更できます。

公開・お気に入り・NEW

「利用者ページに公開する」にチェックを入れて保存すると、利用者画面に表示されます。カードの星でお気に入りを切り替え、「利用者ページにNEWラベルを表示する」で、利用者向けに新着の目印を付けられます。

公式リンク

左メニューの「公式リンク」を開き、フォームに名前とURLを入力して追加します。登録済みの公式リンクは一覧から削除できます。

削除とゴミ箱

通常リンクのカードで「削除」を押すとゴミ箱に移ります。直後は「元に戻す」、後からは「ゴミ箱」の「復元」を使います。「完全に削除」や「ゴミ箱を空にする」を実行すると復元できません。

リンク診断

「リンク診断」を開いて「診断する」を押します。開けない可能性があるURLや、重複して登録されたURLを確認できます。

管理者専用チャット

「チャット」→「管理者専用チャット」を開きます。メッセージが画面に表示されると、そのブラウザの未読投稿だけを自動で既読にします。過去の既読情報と他の管理者の既読は維持されます。通信に失敗した場合は「既読にする」を手動でも使えます。右上の未読通知からもチャットを開けます。

利用者チャット

「チャット」→「利用者チャット」は全員が参加する共通チャットです。個別に話す場合は「利用者個人チャット」の一覧、またはクリック履歴の「個人トーク」から相手を選びます。

サブブラウザを設定

メインブラウザで左メニューの「サブブラウザを設定」を開いてコードをコピーします。サブブラウザで同じ画面を開き、貼り付けて「サブとして登録」を押します。連携後は、サブからの新規投稿も自分の投稿として扱われます。

メモ帳

左メニューの「メモ帳」を開き、専用パスワードを入力します。メモは新規作成でき、一覧から開いて編集・削除できます。

リンク操作履歴

「ログ」→「リンク操作履歴」で、通常リンクの追加・編集・削除の日時とリンク名を確認できます。最新の記録を見るには「再読み込み」を押します。

利用者ログイン履歴

「ログ」→「利用者ログイン履歴」で、ログイン成功日時とブラウザIDを確認できます。各行の「削除」で1件ずつ、表の上のボタンですべて削除できます。

クリック履歴

「ログ」→「クリック履歴」で、利用者が開いたリンクと日時、ブラウザIDを確認できます。各行の削除と全件削除ができます。

共有とログアウト

「このページを共有」で利用者画面のURLやQRコードを共有できます。「ログアウト」は現在のセッションを終了し、「全ブラウザをログアウト」は管理者と利用者の発行済みセッションを一括で失効させます。

リンクを追加

選択したフィルターを登録している利用者には、このリンクを表示しません。PCではCtrl／⌘を押しながら複数選択できます。

サブブラウザを設定

ⓘ 使い方
  1. メインブラウザで「サブブラウザを設定」を開き、「このブラウザの連携コード」をコピーします。
  2. サブブラウザでも管理者としてログインし、同じ設定画面を開きます。
  3. 「メインブラウザのコード」に貼り付けて、「サブとして登録」を押します。

連携すると、管理者専用チャットでニックネーム・既読・オンライン状態を共有します。元に戻すには、サブブラウザで「連携を解除」を押してください。

このページの仕組み

画面の配信は GitHub Pages、ログインやデータの処理は Google Apps Script、保存先は Google スプレッドシートです。「リンクを更新」を押すと、次の順で処理が進みます。

1. GitHub Pages が画面を配信する

GitHub Pages は index.html（利用者画面）、admin.html（管理者画面）、memos.html（メモ帳）を配信します。見た目やボタンの操作は、ブラウザ上で HTML・CSS・JavaScript が担当します。

2. bridge.html が通信を中継する

画面を開くと、Apps Script が提供する bridge.html が非表示の iframe に読み込まれます。画面と中継ページは postMessage で依頼と結果をやり取りし、中継ページは google.script.run で GAS の関数を呼び出します。

3. Google Apps Script が処理する

Code.gs がパスワードやセッション、操作権限を確認し、リンクの取得や保存を処理します。CacheService は一覧などを一時保存し、同じデータを繰り返し読み取るときの負荷を減らします。

4. Google スプレッドシートに保存する

GAS は SpreadsheetApp を使って、リンク・メモ・チャットなどを読み書きします。これらのデータはスプレッドシートに残るので、画面を閉じても保存内容を次回読み込めます。

読み取った結果は GAS から中継ページに戻り、postMessage で画面へ届きます。画面の配信は静的で、データの読み書きは操作に応じて動的に行います。
