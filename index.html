このページの仕組み

画面の配信は GitHub Pages、ログインやデータの処理は Google Apps Script、保存先は Google スプレッドシートです。「リンクを更新」を押すと、次の順で処理が進みます。

1. GitHub Pages が画面を配信する

GitHub Pages は index.html（利用者画面）、admin.html（管理者画面）、memos.html（メモ帳）を配信します。見た目やボタンの操作は、ブラウザ上で HTML・CSS・JavaScript が担当します。

2. bridge.html が通信を中継する

画面を開くと、Apps Script が提供する bridge.html が非表示の iframe に読み込まれます。画面と中継ページは postMessage で依頼と結果をやり取りし、中継ページは google.script.run で GAS の関数を呼び出します。

3. Google Apps Script が処理する

Code.gs がパスワードやセッション、操作権限を確認し、リンクの取得や保存を処理します。CacheService は一覧などを一時保存し、同じデータを繰り返し読み取るときの負荷を減らします。

4. Google スプレッドシートに保存する

GAS は SpreadsheetApp を使って、リンク・メモ・チャットなどを読み書きします。これらのデータはスプレッドシートに残るので、画面を閉じても保存内容を次回読み込めます。

読み取った結果は GAS から中継ページに戻り、postMessage で画面へ届きます。画面の配信は静的で、データの読み書きは操作に応じて動的に行います。
